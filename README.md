# VAP Guides, Slides, Videos, and Build Scripts

Workshop curriculum, presentation decks, instructor prep guides, comprehensive A4 PDFs, 3D animations, diagrams, and asset generators for the **5-Day Value Added Program (Department of ECE, Acharya Institute of Technology, Bengaluru)**.

## Contents
- `syllabus.md` & `implementation_plan.md` — 5-day syllabus, rubric, and build plan
- `slides/` — 5 daily PowerPoint decks (`Day1`–`Day5`) with embedded click-to-play 3D videos
- `instructor_guides/` — 5 daily instructor prep PDFs (`Instructor_Day1_Prep.pdf`–`Instructor_Day5_Prep.pdf`)
- `VAP_Pre_Workshop_Setup_Guide.pdf`, `VAP_Student_Workshop_Guide.pdf`, `VAP_Instructor_Preparation_Guide.pdf` — Comprehensive A4 workshop handbooks
- `videos/` — 7 procedural 3D animations (`.mp4`) and poster images (`_poster.png`)
- `images/` & `images/ppt/` — Architecture diagrams, terminal output captures, and slide visuals
- Build scripts: `build_vap_ppts.py`, `build_instructor_prep_pdfs.py`, `build_comprehensive_a4_vap_pdfs.py`, `generate_ppt_visuals.py`, `create_vap_diagrams_v2.py`, `render_vap_3d_videos.mjs`
